## What's new in 0.4.0

**Automatic updates**
- SubTrack now checks for new versions by itself (1 minute after starting, then every 6 hours)
- New versions are downloaded in the background and their checksum is verified before anything runs
- If *Install updates automatically* is on (the default), the update installs while SubTrack sits in the tray, or when you quit it, and SubTrack starts again afterwards
- Otherwise a **Restart to update** button appears in the status bar
- *Check for updates* in the tray menu and in Settings; both settings can be turned off in Settings

**Upgrading from 0.1 – 0.3**
- Install this version once by hand (download `SubTrack-0.4.0-setup.exe` below). From then on, updates arrive automatically. Your data is kept.

## Downloads

- **SubTrack-0.4.0-setup.exe** – installer (recommended)
- **SubTrack-0.4.0-portable.zip** – unzip and run `SubTrack.exe` (portable copies notify you about updates but can't install them)
- **SHA256SUMS.txt** – checksums
